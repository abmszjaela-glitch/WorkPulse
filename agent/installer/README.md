# WorkPulse Agent installer

Use the root WorkPulseAgent.iss through build_release.py. See ../BUILD_RELEASE.md for the maintained build, verification, privacy and uninstall instructions. Output is ../release/WorkPulseAgentSetup.exe.

PRIVACY.txt and USER_GUIDE.txt are installed runtime documentation and must be retained. verify_release.py checks installation, shortcuts, visible GUI startup and uninstall in an isolated current-user directory.
